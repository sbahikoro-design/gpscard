Règles

On part d'un mot et on doit arriver au mot cible.
  1. À chaque coup, on change une seule lettre (sans changer l'ordre ni le nombre de lettres).
  2. Le nouveau mot doit être un vrai mot français (pluriels et verbes conjugués acceptés, accents ignorés).
  3. On ne peut pas réutiliser un mot déjà écrit.
  4. Les lettres déjà bien placées sont soulignées en vert.
Comment jouer : touche une lettre du mot, puis la nouvelle lettre sur le clavier (ou tape-la directement : elle remplace la lettre sélectionnée). Valide avec ✓ ou Entrée.

2 joueurs : chacun son tour change une lettre, comme sur le tableau blanc. Celui qui écrit le mot cible gagne la manche (+1). Un coup invalide fait passer le tour.

Exemple : ROCK → ROCS → ROIS → BOIS → BOIT → BOUT → COUT → COUR → TOUR → TOUX → DOUX → DEUX → JEUX.
