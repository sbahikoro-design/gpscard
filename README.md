# BS MAGIC KEYBOARD
Le téléphone devient **clavier + souris** de l'ordinateur.

- **Bluetooth** (recommandé) : le téléphone se déclare comme un vrai clavier/souris Bluetooth. Rien à installer sur le PC — il suffit de l'associer (Paramètres › Bluetooth › Ajouter un appareil).
- **Wi-Fi** : lancer `BS_MAGIC_KEYBOARD_PC.exe` sur le PC, puis « Rechercher les ordinateurs » dans l'appli et saisir le code à 4 chiffres affiché.

Fonctions : pavé tactile (clic, clic droit à 2 doigts, défilement, glisser-déposer par appui long), molette, boutons gauche/milieu/droit, souris gyroscope, saisie directe en AZERTY ou QWERTY (accents compris), Ctrl/Maj/Alt/Win, flèches, F1-F12, raccourcis Windows / édition / navigateur, télécommande PowerPoint, touches multimédia.

APK et programme PC : onglet **Releases** (tag `bs-magic-keyboard-v1.0.N`).
