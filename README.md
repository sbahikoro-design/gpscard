# BS NOTIF SPEAK
Le téléphone **lit vos notifications à haute voix** (WhatsApp, SMS, Telegram, Messenger… ou toute autre appli choisie).

- **En marche par défaut** dès l'installation, et **redémarre tout seul** à chaque allumage du téléphone.
- **Grand bouton marche/arrêt** dans l'appli + bouton rapide « Notif Speak » dans le volet des réglages.
- **Choix des applications** à lire (recherche, raccourci « Messageries »).
- **Voix** : toutes les voix du téléphone, **voix africaines en tête de liste**, puis françaises ; choix du moteur ; tons Grave / Posé / Naturel / Vif ; vitesse et hauteur réglables ; bouton d'essai.
- **Ce qui est lu** : appli + nom + message, nom + message, ou simple annonce. Nom du groupe WhatsApp, liens remplacés par « un lien », émojis retirés, messages longs tronqués.
- **Se tait** pendant les appels, en silencieux / Ne pas déranger, aux heures de silence choisies, ou quand l'écran est allumé (au choix).
- Historique des derniers messages lus.

APK : onglet **Releases** (tag `bs-notif-speak-v1.0.N`).
