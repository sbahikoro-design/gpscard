# BS CALLMagic

Application Android d'échange **sans Internet** entre deux téléphones, par **Wi-Fi local** (même réseau ou point d'accès) ou par **Bluetooth** :

- 💬 messages instantanés
- 📎 envoi de fichiers (photos, vidéos, documents, APK…) — rangés dans `Téléchargements/BS CALLMagic`
- 📞 appels vocaux (haut-parleur, coupure du micro, annulation d'écho)

## Installation
Télécharger `BS_CALLMagic.apk` dans la page *Releases* (tag `bs-callmagic-v1.0`) et l'installer sur les deux téléphones.

## Compilation
Automatique par GitHub Actions à chaque envoi sur la branche `bs-callmagic`.
